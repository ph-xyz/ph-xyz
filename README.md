# Hey, I'm Pedro

I study web security and spend a lot of time figuring out how applications work behind the scenes.

Most of my testing revolves around authorization, sessions and business logic. I'm especially interested in understanding why something works the way it does, and what happens when the backend trusts the wrong thing.

I also like building tools and small labs to explore ideas instead of just reading about them.

### Some of my work

**[CaidoBridge](https://github.com/ph-xyz/Caido-Bridge)**

A tool I built to connect ChatGPT with Caido, inspect HTTP traffic and replay requests within a defined scope.

**[Web Security Labs](https://github.com/ph-xyz/web-security-labs)**

Small vulnerable applications I use to practice and understand different web security issues.

**[Web Security Writeups](https://github.com/ph-xyz/web-security-writeups)**

Notes and writeups from my testing, including a [section for Bug Bounty and VDP findings](https://github.com/ph-xyz/web-security-writeups/tree/main/bug-bounty-vdp).

Lately I've been spending more time learning about backend design and how security issues emerge from application logic.
